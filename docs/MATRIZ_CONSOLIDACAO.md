## Testar no Windows sem dados reais

1. Utilizar o checkout da branch do PR #8 em uma pasta **fora do OneDrive**. Não copiar documentos financeiros para o checkout.
2. Executar `py -3 -m http.server 8000 --bind 127.0.0.1` e abrir `http://127.0.0.1:8000/`.
3. Investimentos → INSS — Histórico e conferência → Demonstração fictícia. A única tabela contém os campos antigos e a prévia, sem aplicação. Ajustar o período pelo filtro existente para ver competências antigas.
4. Conciliação, logo após Despesas → Usar demonstração fictícia. Filtrar, marcar, recarregar/reabrir o histórico e exportar XLSX privado com consentimento.
5. Configurações → Importações → definir a raiz privada **somente se quiser testar fontes reais depois**. Salvar não move/ativa nada. OneDrive real no localhost depende da sessão própria e redirect URI Microsoft autorizado; os testes simulados não comprovam isso.

Não é necessário novo teste financeiro MCP. Corte de JSONs, criação/ACLs dos destinos, sincronização externa de histórico, aplicação de candidata ou tabela INSS e qualquer importação real que altere históricos exigem procedimentos/revisão e autorização específicos. A interface não deve ser usada como atalho para essa aprovação.
